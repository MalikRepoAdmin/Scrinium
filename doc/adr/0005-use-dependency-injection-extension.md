# 5. Use Dependency Injection Extension

Date: 2026-06-27

## Status

Accepted

## Context

We need to avoid registering every services and ViewModels directly into App.axaml.cs

## Decision

Installed Microsoft.Extensions.DependencyInjection and make new static class for DI, then call ConfigureService() into App.axaml.cs

We will register all services, View, and ViewModels into DependencyInjection.cs

## Consequences

Keeping the main apps initialization generated by the framework to stay clean.
